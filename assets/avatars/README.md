# Avatar-Medien

Lege hier deine täglichen Avatar-Clips oder -Bilder ab.

- Bevorzugt **Video** (`.mp4`), z. B. `tag-01-berlin.mp4` — der Avatar läuft durch die Stadt.
- Zusätzlich ein **Standbild** (`.jpg`) als Poster/Vorschau, z. B. `tag-01-berlin.jpg`.
- Dateinamen frei wählbar — sie werden in `data/journey.json` referenziert
  (`avatarMedia`, `avatarPoster`).

Empfohlenes Seitenverhältnis: **4:5** (passt zum Layout und zu Instagram/TikTok).

# Produktfotos

Lege hier die Fotos der beworbenen Produkte ab (z. B. `handtasche.jpg`, `kaffeebecher.jpg`).

- Bevorzugt **quadratisch** (1:1) für ein einheitliches Karten-Layout.
- Referenziert werden sie in `data/journey.json` über das Feld `image`.
- Nutze bevorzugt eigene/erlaubte Produktbilder. Amazon-Produktbilder dürfen nur im Rahmen
  der Amazon-Partnerbedingungen bzw. über die Product Advertising API verwendet werden.

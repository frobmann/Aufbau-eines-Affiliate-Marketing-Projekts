# Projekt-Roadmap — Avatar Journey

Vom heutigen MVP bis zur skalierten Affiliate-Maschine. Jede Stufe ist eigenständig nutzbar.

## ✅ Stufe 0 — MVP (dieses Repo, fertig)
- Web-App zeigt täglich Avatar + Stadt + Produkte.
- Reise startet in **Berlin**, Timeline der besuchten Städte.
- Amazon-Partnerlinks werden automatisch aus ASIN + Partner-Tag gebaut.
- Werbekennzeichnung & Amazon-Pflichthinweise integriert.
- Tages-Pflege über eine einzige Datei (`data/journey.json`).

## 🔜 Stufe 1 — Inhalte & Betrieb
- [ ] Echten Avatar in Kling/Hedra erstellen (Berlin-Clip) → `assets/avatars/`.
- [ ] Amazon-Partner-Tag eintragen.
- [ ] Impressum + Datenschutz mit echten Daten füllen.
- [ ] Erste 7 Reisetage (Berlin → weitere Städte) vorproduzieren.
- [ ] Veröffentlichung über GitHub Pages.

## 🔜 Stufe 2 — Automatisierung der Produktpflege
- [ ] Anbindung der **Amazon Product Advertising API (PA-API 5.0)** für korrekte
      Preise, Bilder und Verfügbarkeit (statt manueller Eingabe).
- [ ] Kleines Admin-Formular statt JSON-Handpflege.
- [ ] Bild-Upload-Helfer für Produktfotos.

## 🔜 Stufe 3 — Reichweite & Tracking
- [ ] Klick-Tracking (welche Produkte werden geklickt?) — z. B. Plausible/Umami
      (datenschutzfreundlich).
- [ ] Automatischer Export der Tages-Clips für **TikTok / Instagram Reels / YouTube Shorts**
      inkl. Link-in-Bio-Seite.
- [ ] UTM-Parameter für Kanal-Auswertung.

## 🔜 Stufe 4 — Skalierung
- [ ] Mehrere Amazon-Länder (`amazon.de`, `.com`, `.co.uk`) je nach Besucherland.
- [ ] Themen-Serien (z. B. „Reise-Gadgets-Woche").
- [ ] Newsletter/Community (Achtung: keine Amazon-Links in E-Mails!).
- [ ] Ausbau zu mehreren Avataren/Marken.

## Kennzahlen, die zählen (KPIs)
- Klickrate auf Produkte (CTR)
- Conversion-Rate auf Amazon
- Umsatz je Reisetag / je Stadt
- Wachstum der Social-Follower & Link-in-Bio-Klicks
